# 02-custom-dns

Учебный DNS-сервер.

Использует UDP, следует RFC 1035.

Есть локальная таблица известных записей (KnownResources в
cmd/dnsd/storage.go), запросы для ресурсов вне таблицы
пересылаются на настоящий dns сервер (upstream).

## Запуск

    go build -o dnsd ./cmd/dnsd
    ./dnsd -listen 127.0.0.1:12345 -upstream 1.1.1.1:53

Флаги:

- -listen - локальный адрес и порт;
- -upstream - адрес DNS-сервера, на который пересылаются неизвестные вопросы;
- -max-inflight - максимум одновременных запросов к upstream.

## Проверка

Скрипт run.sh собирает сервер, запускает docker-контейнер,
который использует этот сервер по умолчанию.

Запускать так:
```
./run.sh 8.8.8.8:53
```

Если не указать upstream, то будет использоваться 1.1.1.1:53 (cloudflare).
